# PocketSmart AI – Your Smart Budget & Recommendation Assistant

This project follows the project structure described in the submitted project document.

## Modules
1. Home Interior Budget Planner
2. Party Budget Planner
3. Jewelry Budget Planner

## Technology
- Python
- FastAPI
- Uvicorn
- Jinja2
- HTML/CSS/JavaScript
- Gemini AI integration

## Setup
1. Create a Python virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Copy `.env.example` to `.env`.
4. Add your Gemini API key.
5. Run:
   `uvicorn app.main:app --reload`
6. Open `http://127.0.0.1:8000`

See the source files for the implementation steps.
